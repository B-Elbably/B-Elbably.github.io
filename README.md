# bably.me

Personal site of Belal Elbably, built with [Astro](https://astro.build) as a static pixel-space themed portfolio and served by GitHub Pages at <https://bably.me>.

## Run locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
npm run preview  # serves dist/
```

## Edit content (no component changes needed)

| What | File |
| --- | --- |
| Scoreboard numbers | `src/data/stats.json` |
| Projects and their pixel planets | `src/data/projects.json` |
| Leadership timeline | `src/data/community.json` |
| Handles, links, public email | `src/data/profiles.json` |

To show an email button on the Contact page, set `email` in `src/data/profiles.json`. Add a `demo` URL to a project to show a LIVE link on its card.

## Design

- Tokens (colors, fonts, spacing) are at the top of `src/styles/global.css`.
- Fonts are self-hosted through `@fontsource` (Press Start 2P, VT323, Inter), so the site makes no third-party requests.
- Sprites are text grids in `src/lib/sprites.js`. Planets are generated by `src/components/PixelPlanet.astro`.
- The animated background is `src/components/Starfield.astro`: a low-resolution canvas scaled up with pixelated rendering, with parallax star layers, a dithered nebula and shooting stars.
- The header has a motion toggle. Motion starts off for visitors with `prefers-reduced-motion`, and the choice is remembered.
- Easter egg: the Konami code triggers a meteor shower.

## Deploy

`.github/workflows/deploy.yml` builds and publishes to GitHub Pages on every push to `main`.

One-time setup in the repository: **Settings, Pages, Source: GitHub Actions**, custom domain `bably.me`, then enable **Enforce HTTPS** once the certificate is issued. `public/CNAME` keeps the custom domain across deploys.
